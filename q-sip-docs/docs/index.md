# Welcome to QSIP

The purpose of this project is to implement database backends to [PyZX](https://github.com/zxcalc/pyzx).
It uses PyZX as a dependency, and tries to route and reimplement the few pieces of logic needed so that all calculations would eventually occur inside a database.
The benefit of this is increased speed of computation (if the DB is well optimized) compared to vanilla PyZX and storing multiple graphs.

**Currently supported backends**


|Backend | status | info |
|--------|--------|------------|
|Neo4j  | ✅ | not actively worked on|
|memgraph|⚠️ | xxxx|
|Postgres/age| ⚠️ | xxx|

The main idea is that the software would be used like PyZX in the most part.
All the queries are easily available to users and researchers to try and modify to A) optimize and B) make valid in case they have any bugs.

The project is a work in progress, and any contributions are of course welcome.
